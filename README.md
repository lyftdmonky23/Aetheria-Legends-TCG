# 🛡️ High-Fantasy WAX Blockchain TCG

Welcome to the official source code and asset repository for our decentralized trading card game built on the **WAX Blockchain**.

## 🌟 Core Game Features
* **4-Tier Progression System:** Players evolve cards through structured rarity tiers to build powerful decks.
* **Branching Final Evolution (Tier 4):** At the apex tier, cards branch into three distinct playstyle variants:
  * ⚔️ **Striker:** High offense and attack focus.
  * 🛡️ **Guardian:** High defense and tank capabilities.
  * 🔮 **Mystic:** Utility and powerful ability mechanics.
* **Utility Token Economy:** Integrated on-chain token sinks powering blending, minting, and upgrades.
